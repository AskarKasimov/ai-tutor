# Голосовой AI-репетитор

ИИ в образовании: диагностика знаний, поиск пробелов, подбор и генерация заданий по карте компетенций. Студент читает вопрос, отвечает голосом и получает балл с объяснением. Состояние и решения актуальны на **5 октября 2026**.

Учебные входы: РПД, карта компетенций, учебные материалы, банк заданий с критериями/эталонами.

## Что реализовано

| Часть | Состояние кода |
| --- | --- |
| Backend | Go + PostgreSQL: auth, импорт CSV/XLSX, типизированная карта, SQLC-репозитории, каталог заданий, генерация, поиск материалов и голосовые/оценочные API. |
| Frontend | React/TypeScript/Vite: семь моковых заданий, запись, расшифровка, балл 0/1/2, три строки фидбэка, итог из 14. Сессия, ответы и аудио живут в памяти вкладки. |
| Оценивание | `gpt-oss-120b` через OpenAI-совместимый API; задание, варианты, инструкция, необязательный эталон и расшифровка владельца. Оценка пока не сохраняется. |
| Карта и банк | `competencies → constituents → outcomes → tasks`, свойства ОР, уровни темы, связки разделов/компетенций РПД и исходные координаты нормализованы. `GET /tasks` фильтрует банк; `GET /tasks/{id}` отдаёт полный учебный профиль без эталона. |
| Генерация/RAG | `POST /tasks/generate` создаёт аналог с локальной LLM, сохраняет запрос/примеры/материалы и сразу публикует задание. Админ загружает учебный текст через `POST /admin/materials`; поиск контекста пока PostgreSQL FTS. |
| Ещё предстоит | Frontend-подключение каталога/генерации, рабочий сценарий учебных сессий/снимков и сохранение диагностических результатов. Схема исторических снимков уже добавлена. |

Backend вызывает **GigaAM STT**, **VoxCPM2 TTS** и LLM; браузер обращается только к backend через Caddy. Наличие кода не подтверждает доступность удалённых моделей или применение миграций на сервере.

## Согласованные правила

- **ОР — тема**, отдельная сущность `Topic` не нужна. Карта связывает компетенцию, составляющую, ОР, таксономию, ALDs, важность, включение в тест, уровень темы, раздел и компетенции РПД, ОС и задания. Все имена таблиц и полей — английские.
- **ОС ↔ ОР: 1:1**; отсутствующий текст ОС — `NULL`. Задания 1–3 одного ОР равнозначны, имеют общий профиль и используются как аналоги. Пустая ячейка означает отсутствие задания.
- Повторная загрузка **атомарно заменяет карту, банк и связанные поисковые данные**; пользователи и расшифровки остаются, ошибка импорта откатывает замену.
- Генерация использует профиль ОР, примеры и найденные FTS-фрагменты; `Idempotency-Key` исключает дубли повтора, проверка ревизии блокирует устаревший результат. Сгенерированное задание сразу попадает в общий банк.
- Вопрос и варианты показываются текстом; **TTS должна читать только инструкцию**. Ответ — голосовой выбор и объяснение, без ручной правки расшифровки. Сейчас кнопка frontend озвучивает вопрос с вариантами — есть расхождение с требованием.
- **2** — полностью верное объяснение; **1** — частичное понимание с ошибкой; **0** — неверно/нет понимания. Если требуется назвать вариант и объяснить, отсутствие названия варианта словами даёт 0; одного номера недостаточно. Фидбэк — три короткие строки. Техническая ошибка не считается учебным нулём.
- Полный сценарий: **7 основных заданий** выбранного ОР; после частичного/неверного ответа — **2 базовых** по явно связанным дочерним ОР, без рекурсивных веток и досрочного завершения. Балл — только по основным, максимум 14.
- Тренировка проходит в том же `Session.id`: до двух других, неиспользованных заданий на каждый проверенный неподтверждённый ОР; диагностический итог не меняется. Нехватка банка — `tasks_exhausted`; непроверенные ОР не объявляются пробелами.

## Данные и импорт

PostgreSQL хранит пользователей, auth-сессии/токены, расшифровки, карту, задания, генерации, материалы и таблицы снимков учебных выдач/ответов. Frontend пока использует моковую сессию и не вызывает новый каталог/генерацию. Данные PostgreSQL сохраняются в Docker volume.

Admin загружает CSV или `.xlsx` через `POST /admin/competency-map/import`. Поддерживаются парный формат `Ком/Сост/ОР + Задание N/Критерии N` и исходная карта ML. Критерии парного формата сохраняются без интерпретации. Импорт ML выделяет вопрос, варианты, инструкцию и эталон; все строки источника и фрагменты заданий сохраняются с логическими и физическими координатами.

Текущий CSV ML: **13 компетенций, 17 составляющих, 101 ОР, 13 самостоятельных заданий; 41 непустая ячейка с фрагментами заданий**. Фрагменты не выдаются студенту как готовые вопросы. ОС заполнена у 18 ОР. Карта сама по себе пока не обеспечивает банк из семи заданий на выбранный ОР.

Схема, шаги и реализационный статус: [PLAN.md](PLAN.md). Текущая схема для draw.io: [current-storage.drawio](documents/current-storage.drawio). SQLC запросы: `services/backend/internal/shared/postgres/queries`; генерация — `cd services/backend && go run github.com/sqlc-dev/sqlc/cmd/sqlc@v1.30.0 generate -f sqlc.yaml`.

## Запуск и окружение

Локально нужны Docker Compose и mkcert:

```bash
cp .env.example .env
# Настройте пароль БД и режимы API в .env.
./dev.sh -d
```

Приложение: [https://localhost:8443](https://localhost:8443), API: `/api/v1`, проверка: `/api/v1/health`, Swagger при `COMPOSE_PROFILES=swagger`: `/docs/`. Health проверяет backend/БД, а доступность моделей проверяется отдельно.

Для сервера: скопировать `.env.prod.example` в `.env`, задать пароль/адреса моделей, подготовить `certs/server.pem` и `certs/server-key.pem`, создать сеть `ai-tutor_default`, затем `./prod.sh`. Dev-стек и серверные Compose на одном хосте одновременно не запускаются.

- `VITE_API_MODE=mock` — браузер использует локальные моки; только точное `real` включает HTTP к backend. Учебная сессия пока моковая в обоих режимах.
- `BACKEND_API_MODE=mock` — backend подменяет STT/TTS/LLM; авторизация и БД настоящие. `real` использует модели по `BACKEND_STT_URL`, `BACKEND_TTS_URL`, `BACKEND_ASSESSMENT_BASE_URL`, `BACKEND_ASSESSMENT_MODEL`.
- Backend-настройки и таймауты берутся из полного шаблона `.env`; адреса моделей обязательны в `real`. Frontend env встраивается при сборке. Секреты остаются на backend.
- STT принимает multipart `audio` (WAV/Ogg/WebM, до 25 МиБ), возвращает готовый текст; TTS принимает JSON `text` до 500 символов и возвращает WAV. Для речи длиннее 25 секунд удалённому GigaAM нужны longform-зависимости/VAD. Публичный API не ограничивает длительность.
- Применённые SQL-миграции дополняются следующей версией. `docker compose down` сохраняет БД; `down -v` удаляет volume.

## Контракты, сроки и документация

Реальные маршруты включают `/auth/*`, `/admin/competency-map/import`, `/admin/materials`, `/tasks`, `/tasks/{id}`, `/tasks/generate`, `/voice/*`, `/assessments/evaluate` и `/health`; публичный префикс — `/api/v1`. Доступ — HTTPS и `Secure; HttpOnly; SameSite=Lax` cookies. Эталоны и критерии не выдаются каталогом студенту.

Целевые этапы 2026: **7 октября** — учебная база и оценивание; **14 октября** — полный MVP/демо диагностики и тренировки; **1 ноября** — устойчивость, повторы и восстановление.
