# Единый HTTP API

Контракт: [openapi.yaml](openapi.yaml), OpenAPI 3.1. Все пути относительны к `/api/v1`.

- `x-implementation: implemented` — подключённая операция: общие auth и voice, обучение (`/learn`), экзамен Geek (`/exam`) и health.
- `x-implementation: planned` — проект до реализации; наличие planned-операции не означает наличие handler.

Материалы реализованы: `GET /exam/admin/material-kinds`, загрузка `POST` и список `GET /exam/admin/subjects/{subject_id}/materials`, правка недели/вида `PATCH .../materials/{material_id}`,
замена PDF `PUT .../materials/{material_id}/raw`, скачивание и удаление. Загрузка
принимает до 48 файлов; manifest `items` задаёт `client_id`, неделю и вид каждого
файла, а `results` связывает ответ с записью очереди. Старый multipart без manifest
сохраняет совместимость. Метаданные не запускают OCR; замена файла ставит новое
фоновое задание и отменяет устаревшие результаты предыдущего исходника.

Граф master: `GET /exam/admin/subjects/{subject_id}/graph` возвращает snapshot со статусом,
сохранённым графом, `stale`, `inputs_ready` и `progress` идущей сборки (этап и шаги); `POST /exam/admin/subjects/{subject_id}/graph/build` запускает сборку.
Отдельный GET статуса по `/graph/build` не используется интерфейсом.
Диагностика реализована: `POST`/`GET /exam/diagnostic-sessions`, чтение сессии,
`/{id}/answers`, `/{id}/result`, `/{id}/turns/{turn_id}/audio`. Ограничение «ровно одно
из `transcription_id`, `text`, `dont_know`» проверяет код: генератор не выражает `oneOf`.
Импорт учебной карты поддерживает необязательный заголовок `X-Expected-Map-Revision`; при несовпадении текущей ревизии возвращается 409 без замены карты.

Учебный поток включает импорт карты, варианты, диагностику, план и тренировку на маршрутах `/learn`. Пакет Geek для преподавателя остаётся planned: список диагностик курса и отчёт.

Внутренний API Python-сервиса course-graph — отдельный контракт [course-graph.yaml](course-graph.yaml): OCR, задание на сборку графа и его статус. Он не публикуется через Caddy.

Фикстура графа — [fixtures/course-graph.json](fixtures/course-graph.json): `Graph` по `course-graph.yaml`, 10 тем демокурса (поиск, недели 3 и 5–7) на русском. В ней есть цепочка пререквизитов глубиной 3, общие пререквизиты у тем верхнего уровня (`heuristic`, `uninformed-search`, `exploration-exploitation`), тема без связей (`agents-peas`) ОР заполнены только у `a-star`, основной вопрос заранее сгенерирован у всех вершин (`api prepare-questions`). Верхний уровень: `a-star`, `simulated-annealing`, `mcts`, `agents-peas`. Подходит для тестов экзамена и моков frontend.

Полная русская фикстура курса Introduction to AI — [fixtures/intro-to-ai.ru.graph.json](fixtures/intro-to-ai.ru.graph.json): 132 учебные темы и 20 диагностических групп, каждая сериализована как обычный `GraphNode`; порядок вершин топологический. Пять тем без учебного материала исключены. Направление 145 исходных учебных рёбер сохранено; у каждой диагностической группы её верховые темы указаны как `prerequisites`. В группах есть черновые комплексные вопросы. Это фикстура переведённого содержимого для интеграции с Geek, не новая версия OpenAPI-контракта.

Граф показа — [fixtures/intro-to-ai.weeks-1-2.ru.graph.json](fixtures/intro-to-ai.weeks-1-2.ru.graph.json): 16 тем недель 1–2 (лекции недель 1 и 2, туториалы недель 1 и 2) с ID, ОР и связями полного графа, без диагностических групп. Тексты — выдержки из PDF без меток источников; ссылка на пререквизит из другой недели (`AI-02-01`) убрана. Верхний уровень — 10 тем, самая длинная цепочка — AI-01-13 → AI-01-14 → AI-01-15 → AI-01-18. Основной вопрос задан у всех вершин. Был графом по умолчанию до решения 19.10.2026, которое удалило фикстуру графа: теперь файлы `fixtures/*.graph.json` используются только в тестах и для просмотра.

Для экспертного просмотра граф выгружается в CSV: `api/fixtures/graph-json-to-csv.sh <граф>.json` (нужен `jq`) пишет `<граф>.csv` рядом с JSON — UTF-8 с BOM, колонки «Компетенция / тема», «Материал курса», «Образовательный результат», «Вопрос / критерий оценки» (вопросы и `assessment_guidance`), «Предварительные темы» (названия; «Нет» у тем верхнего уровня). Одна строка на ОР, тема без ОР — одной строкой с пустым результатом. Переформулировок в CSV нет: в файле графа их нет — у опубликованного графа их готовит worker сборки перед публикацией. [fixtures/intro-to-ai.weeks-1-2.ru.graph.csv](fixtures/intro-to-ai.weeks-1-2.ru.graph.csv) — выгрузка графа показа; файл сгенерирован, вручную не правится: после изменения JSON запустите скрипт заново.

Учебный `GET /learn/subjects/{subject_id}/diagnostic-outline` возвращает только
блоки, отобранные общим алгоритмом `constituent-map-v1`: компетенции, составляющие
и три ОР на составляющую (main и два basic). Просмотр не создаёт вариант или
диагностическую сессию и не выдаёт вопросы, эталоны, criteria и ОС.

Из `services/backend` контракт обновляется командой `bash scripts/generate-openapi.sh`. Генератор обновляет только операции, уже присутствующие в контракте, и сохраняет planned. Новую работающую ручку сначала явно добавьте в `openapi.yaml` со статусом `implemented`, затем запустите генератор. CI проверяет повторяемость генерации; контрактные тесты проверяют схемы и реальные ответы действующих операций. Swagger читает `api/openapi.yaml` через Compose.

Правила продукта — [README](../README.md).

В `GET /learn/subjects/{subject_id}/diagnostic-outline` у компетенций и составляющих есть необязательное `display_name`: короткая подпись, подготовленная через LLM gateway и кэшированная по исходному названию. `name` сохраняет формулировку карты. При недоступности генерации возвращается `503 GRAPH_LABELS_UNAVAILABLE`; повтор безопасен.

Генерация подписей сохраняет все партии в кэш атомарно после общего успеха. Ожидание очереди и каждая партия имеют независимый `llm_gateway.timeout`; deadline HTTP-ответа увеличивается под число партий. Клиент должен допускать такую длительность и отменять запрос через свой сигнал при уходе со страницы.

Граф exam-карты может содержать необязательный массив `assessment_warnings`: элементы `{row, column, message}` сообщают администратору, в каких выбранных заданиях вместо отсутствующих критериев применена общая рубрика. Пустые критерии и отсутствие колонок критериев не являются ошибкой импорта; заполненные невалидные шкалы по-прежнему отклоняются.

Исключение заданий без критериев требует заголовок `X-Expected-Map-Fingerprint` из `map.fingerprint` подтверждённого snapshot. Операция доступна только для успешно опубликованной актуальной карты; отсутствующее или устаревшее подтверждение возвращает 409 `COMPETENCY_MAP_CHANGED`. Проверка при сохранении атомарная.
