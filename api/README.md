# Единый HTTP API

Контракт: [openapi.yaml](openapi.yaml), OpenAPI 3.1. Все пути относительны к `/api/v1`.

- `x-implementation: implemented` — подключённая операция. Реализованы auth, voice, импорт/карта/банк, прототипное assessment и taskgen.
- `x-implementation: planned` — проект до реализации. Описаны создание, список и чтение вариантов, чтение отдельной позиции. Приём ответов, грейдинг и тренировка реализуются другим разработчиком.

Из `services/backend` контракт обновляется командой `bash scripts/generate-openapi.sh`. Генератор обновляет implemented-операции и сохраняет planned. CI проверяет повторяемость генерации; контрактные тесты проверяют схемы и реальные ответы действующих операций. Swagger читает `api/openapi.yaml` через Compose.

Правила продукта — [README](../README.md); правила отбора — [алгоритм](../documents/Алгоритм_составления_варианта.md).
