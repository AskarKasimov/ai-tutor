Variantgen собирает и сохраняет варианты. Backend `diagnostic` выдаёт задания, принимает голосовые ответы, вызывает assessment application по сохранённому варианту, управляет переходами и возвращает результат; состояние хранится в памяти процесса. Mock/real используют graders assessment-модуля. Frontend показывает прохождение и итоговый фидбэк из `diagnosticfeedback`; тренировка не подключена. `/assessments/evaluate` принимает ID расшифровки, сохранённого варианта и позиции; taskgen не менялся.
