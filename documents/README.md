Variantgen реализован для сборки, хранения и чтения варианта. Приём ответов, новый грейдинг, прохождение и тренировка — отдельная работа. Прототипный assessment возвращает фидбэк одного ответа; итоговый фидбэк диагностики не реализован. Действующий LLM-модуль taskgen сохраняется.
