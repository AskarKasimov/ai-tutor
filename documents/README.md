Variantgen собирает и сохраняет варианты. Backend `diagnostic` выдаёт задания, принимает голосовые ответы, вызывает assessment application по сохранённому варианту, управляет переходами и возвращает результат; состояние хранится в PostgreSQL. Assessment всегда вызывает API модели (mock-режим удалён). Frontend показывает прохождение, итоговый фидбэк из `diagnosticfeedback` и план обучения модуля `learning` с чатом наставника; прежний модуль `training` остаётся на backend без UI. Для студента это один процесс — см. [решения встречи](ai-journey-plan.md). `/assessments/evaluate` принимает ID расшифровки, сохранённого варианта и позиции; taskgen не менялся.
