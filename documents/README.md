Variantgen собирает и сохраняет варианты. Backend `diagnostic` выдаёт задания, принимает голосовые ответы, управляет переходами и возвращает результат; состояние хранится в памяти процесса. В mock включён демонстрационный grader. В real-режиме оценивание ждёт context provider для заданий варианта. Frontend, итоговый фидбэк диагностики и тренировка не подключены. Существующий `POST /assessments/evaluate` остаётся отдельным прототипом; taskgen сохраняется.
