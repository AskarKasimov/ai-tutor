Variantgen собирает и сохраняет варианты. Backend `diagnostic` выдаёт задания, принимает голосовые ответы, вызывает assessment application по сохранённому варианту, управляет переходами и возвращает результат; состояние хранится в PostgreSQL. Mock/real используют graders assessment-модуля. Frontend показывает прохождение, итоговый фидбэк из `diagnosticfeedback` и тренировку модуля `training` с сохраняемым чатом репетитора. Целевой сценарий AI Journey объединяет их для студента в один процесс — см. [решения встречи](ai-journey-plan.md). `/assessments/evaluate` принимает ID расшифровки, сохранённого варианта и позиции; taskgen не менялся.
