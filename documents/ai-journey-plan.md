# Решения встречи 10.10.2026: сценарий для AI Journey

Статус: согласовано 10 октября 2026, в коде пока не реализовано. Документ задаёт целевой пользовательский сценарий для демонстрации на AI Journey. Пока код не изменён, текущее поведение описывают [README](../README.md), [сценарий тренажёра](voice-trainer-scenarios.md) и [OpenAPI](../api/openapi.yaml). При расхождении целевого сценария с реализацией изменения вносятся в код, контракт и документы вместе.

## Принципы

- **Без «внутрянки».** Студент и демонстрация не видят загрузку карты компетенций. Карту будут генерировать отдельные процессы; импорт остаётся служебной операцией backend и администратора, но в демо-сценарии не показывается.
- **Один процесс.** Для пользователя нет двух разных процессов «диагностика» и «тренировка»: это один путь — проверка, план, тренировка. На backend модули `diagnostic` и `training` пока остаются раздельными; объединение выполняется в пользовательском сценарии.
- **Голос везде.** Студент отвечает голосом на все задания, включая multiple choice: вариант называется словами и объясняется. Возвращается кнопка с микрофоном.
- **Голос наставника.** TTS-голос — мужской, взрослый, низкий (визуальный и звуковой образ наставника).
- **Без оценок в процессе.** После ответа на вопрос результат не показывается: студента быстро проводят по вопросам, итог сообщается в конце.
- **Положительное закрепление.** Сначала отображается большее количество заданий, затем выполненные «схлопываются». Конкретный UX отображения заданий предлагает Марина.
- **Прогресс.** Пока — status bar в процентах.

## Целевой сценарий

1. Студент выбирает предмет и начинает. Отдельного выбора «Диагностика / Тренировка» нет.
2. **Проверка (диагностика).** Задания берутся из ОР с флагом TRUE; на компетенцию — одно основное и два базовых. При сравнении ОР для выбора основного таксономия (ранг Блума) важнее важности ОР. Ответы голосовые, без показа балла и вердикта после каждого вопроса; прогресс — процентами.
3. **Итог проверки.** Показывается общий фидбэк: в каких компетенциях всё хорошо и какие темы не освоены, с указанием образовательного результата (ОР). Балл и пометка «Не проверено» из итога убираются.
4. **Время на тренировку.** В целевом сценарии после фидбэка задаётся вопрос «Сколько у тебя есть времени на тренировку?». До AI Journey этот шаг не показывается.
5. **План.** Выдаётся план в формате «тема — образовательный результат» и кнопка «Начать тренировку». Для списка неосвоенных тем/компетенций добавляются два столбца: время на теорию и время на отработку ОР.
6. **Тренировка.** По завершении — обратная связь, индикатор положения в тренировке (прогресс-бар слева) и кнопка «Продолжить тренировку».

## Влияние на текущую реализацию

| Область | Сейчас | Целевое изменение |
| --- | --- | --- |
| Главная | Реализовано: карточка курса с одной кнопкой «Начать/Продолжить обучение», которая ведёт туда, где студент остановился, и подсказкой про голос; плитки тренировки нет. | Тренировка открывается автоматически после итога проверки (пока — кнопкой в итоге). |
| Ответ на задание | Показываются роль-зависимый балл, вердикт и краткий отзыв. | Балл и вердикт не показываются; оценки сохраняются на backend для итога и плана. |
| Итог диагностики | Сумма основных, «не проверено» для непредъявленных базовых, разбор заданий. | Без балла и «Не проверено»; список освоенных компетенций и неосвоенных тем с ОР. |
| План тренировки | Preview: «Неосвоенные темы», «Частичные пробелы в знаниях» или «Свободная тренировка». | План «тема — ОР» с временем на теорию и отработку, кнопка «Начать тренировку». |
| Прогресс | Счётчики и навигатор по темам. | Status bar в процентах; в тренировке — прогресс-бар слева. |
| Голос | Озвучивается сохранённая голосовая инструкция через VoxCPM (`BACKEND_TTS_SEED`, `CFG_VALUE`, `INFERENCE_TIMESTEPS`; отдельной настройки голоса нет); браузерная озвучка `speakInstruction` берёт первый русский голос системы. | Мужской басистый голос в обоих путях. Уже сохранённые WAV сохраняют прежнее звучание, а worker копирует готовый WAV с тем же текстом инструкции, поэтому смена голоса требует отдельной переозвучки. |
| Выбор основного ОР | Максимум суммы ранга Блума и важности; при равной сумме — большая важность (`competency-map-v3`). | Таксономия важнее важности. Точное правило уточняется; изменение потребует новой версии алгоритма, прежние снимки не пересобираются. |
| Админка | Учитель импортирует карту через `/admin/competency-map`. | В демо-сценарии не показывается. |

Внутренние правила оценивания не меняются: основной оценивается в 0/1/2, базовый — в 0/1, диагностическая сумма считается по основным, непроверенные ОР не объявляются пробелами, техническая ошибка не считается учебным нулём, тренировка не меняет исходную диагностику. Меняется только то, что показывается студенту.
