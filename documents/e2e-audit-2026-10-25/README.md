# E2E аудит — 25 октября 2026

## Результат

Проверены оба существующих Playwright spec и workflow, который запускает их в CI. В исходном CI-логе найдено одно падение: real-stack E2E ожидал заголовок «Курсы» на student-маршруте `/exam`. Актуальная согласованная student-страница называется «Симуляция экзамена»; «Курсы» остаётся заголовком административного каталога `/admin/courses`. В [production-stack.spec.ts](../../services/frontend/e2e/production-stack.spec.ts) исправлены оба ожидания — до и после reload. Это согласует тест с текущим UI и сохраняет отдельную проверку admin-заголовка.

Визуальная проверка mock-flow выявила две неполные fixtures: GET карты обучения возвращал незамоканный 404, хотя курс объявлен готовым; exam graph называл источник отсутствующим при опубликованном состоянии курса. Fixture теперь возвращает успешную карту и сохранённый exam graph, импортированный из карты. Перед screenshot тест ждёт, пока карта и граф действительно загрузятся, и проверяет готовое состояние. Реальный код продукта не менялся.

## Изолированный runtime

Для аудита использовались отдельные имена проекта, сети и volumes `ai-tutor-e2e-audit-*`, отдельный HTTPS порт `18443` и mock gateway config из примера. Существующий пользовательский стек не останавливался и его volumes/config/certificates не изменялись. Первый запуск упёрся в занятый порт `19092` у существующего Redpanda; опубликованный наружу порт был убран только у audit Redpanda, сервисы используют внутренний Compose DNS. После этого весь стек стал healthy, HTTPS smoke и браузерный suite прошли. Временный stack удаляется отдельно от пользовательского стека.

## Граница покрытия

Эти два Playwright spec не составляют полное прохождение всех 22 сценариев parity matrix и не проверяют фактическое обучение end-to-end. Не проверены в браузере реальный запуск и прохождение learning diagnostic/урока, запись с физического микрофона, вызов внешней LLM и реальный UI-upload XLSX/PDF. В mock-flow session/audio/API ответы подменены; audio endpoint намеренно возвращает 503. В реальном smoke database чистая, поэтому каталог курсов пуст: там проверены регистрация, маршруты и cookie isolation, не course preparation. Импортные алгоритмы и API имеют отдельные backend проверки, но это не заменяет перечисленные browser E2E.
