# GIC · Пакет передачи графа и диагностического MVP

**Источник данных:** лекции Introduction to AI и РПД, результаты предыдущих этапов разбиения/сопоставления/построения prerequisite-DAG и диагностической группировки. **Статус:** рабочий прототип / не откалиброван на реальных студентах. Дата сборки: 16.10.2026.

## Быстрый старт за 5 минут

1. Начать с `docs/DEVELOPER_HANDOFF.md` — архитектура, UX и критерии готовности для разработчика.
2. Открыть `visual/student_diagnostic_demo.html` в браузере **без сервера и интернета**: выбрать DG-блок, ответить на вопрос, вручную поставить `pass/gap/uncertain`, увидеть рекурсивную проверку предпосылок и маршрут обучения.
3. Открыть `visual/graph_explorer.html`: все 132 учебные темы, 145 prerequisite и 20 супертем с 69 диагностическими связями. Зелёные ноды — атомарные; оранжевые — верховные; фиолетовые — супертемы.
4. Импортировать **канонический** `data/course_graph.v1.json`. Валидация: `schema/course_graph.schema.json`; `schema/gic_types.ts` и `schema/openapi.yaml` — контракт.
5. Проверить алгоритм: из корня папки пакета запустить `python -m unittest discover -s reference -p 'test_*.py' -v` (без сторонних библиотек). Дополнительный аудит датасета: `python qa/check_artifact.py` (требует networkx + jsonschema).

## Смысл терминов (не перепутать!)

`prerequisite (A→B)`: **изучить A перед B**. Атомарная: нулевая входящая степень. Верховная: нулевая исходящая степень. `diagnostic_group (DG-xx)`: **группа вопросов**, не компетенция и не обязательная предпосылка. Стрелка `topic ⇢ DG` — диагностическое покрытие, не учебное знание.

Базовая система **не** помечает предков освоенными после одного правильного ответа на дочернюю тему. Диагностический блок — не один гарантированно достаточный вопрос. Требуются испытания на реальных студентах до включения быстрого массового закрытия.

## Архив оригинальных PDF

Пакет содержит **извлечённый полный текст каждой ноды и источники страниц**, но не дублирует исходные PDF/PNG, чтобы не увеличивать архив на десятки мегабайт. Для показа оригинальных слайдов пользователю приложение должно отдельно загрузить исходный архив `AI_course_cleaned(1).zip` и настроить маппинг путей `source_pages` на файлы в хранилище. Не считать строки `source_pages` открываемыми публичными ссылками.

## Ограничения демо

HTML-макеты рассчитаны на локальное открытие и тестовый ручной выбор оценки, **не на хранение персональных данных**. В браузере нет бэкенда/авторизации/автогрейдера; сессия исчезнет при перезагрузке. Референсный Python engine — пример алгоритма, без базы, идемпотентности POST и распределённой блокировки; это нужно добавить при реализации сервиса.
