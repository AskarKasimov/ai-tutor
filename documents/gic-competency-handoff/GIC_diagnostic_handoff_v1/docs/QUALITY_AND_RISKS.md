# Ограничения исходной карты и исследовательская валидация

- 145 prerequisite-рёбер — содержательные предположения, а не подтверждённые экспертами необходимости. Транзитивно избыточные рёбра удалены из отображаемого DAG (история в upstream `graph.json`).
- Из 137 тем 5 отсутствуют в PDF. Они сохранены как curricular gaps, но не включаются в активную диагностику.
- 80 явных `requires` не сопоставлены с нодами; часть может быть внешними входными знаниями. Нельзя утверждать, что все 80 — недостающие темы курса.
- 20 супертем покрывают 69 терминальных тем, а не заменяют их двадцатью надёжными вопросами. 13 комплексных кейсов пока pilot; 7 — routing only. `auto_close_allowed=false` для каждой группы.
- «Ответил на верховную тему => знает всех предков» — эвристика с неизвестной чувствительностью. В baseline она **отключена**.
- 117 рубрик предыдущей ревизии были поверхностными; не использовать как готовый автогрейдер. Визуальные формулы/схемы в PDF также требуют проверки.
- Привязки к страницам могут включать общий материал двух тем; готовый `full_text` не является редакционно подтверждённым учебником.
- Возможная математическая ошибка: не использовать просто `level` как полноценную topological sort в общем случае; корректную сортировку выполнять по рёбрам. В reference для имеющегося графа сортировка по уровню гарантирует соблюдение всех рёбер, поскольку для A→B выполняется level(A) < level(B).

## Перед production

1. Экспертные ревью 145 связей, сомнительных разделов и 5 curricular gaps.
2. Калибровка вопросов и рубрик на ответах студентов; данные о ложном закрытии предпосылок.
3. Разделение student-mode / teacher-mode и обеспечение приватности evidence.
4. Объективные метрики: вопросы и минуты до диагностики, доля невыявленных пробелов, ошибки градации, переходы в `uncertain`.
5. Версионирование контента и миграция сессий только по утверждённой политике.
