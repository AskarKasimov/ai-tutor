## Адаптивные ветвления

- `pass` → следующая неподтверждённая терминальная компетенция; предки не подтверждаются.
- `gap` → на ближайшую prerequisite-тему; возвращение к другим терминальным по завершении углубления.
- `uncertain` → не скрывать неопределённость, поставить на повтор/ручную проверку.
- Повторный вопрос по уже заданной теме — только как явно запрошенная пересдача/переоценка, не по случайному пересечению двух блоков.

Визуальный кликабельный просмотр графа доступен в `visual/graph_explorer.html`, а интерактивный учебный макет — в `visual/student_diagnostic_demo.html`.
