# Визуализация

- `full_graph.svg`: **все 132 темы + 20 диагностических супертем**, 145 рёбер prerequisite (сплошные стрелки) и 69 связей диагностического покрытия (штриховые фиолетовые). Пять тем без материалов не входят в активный граф.
- `full_graph.png`: растровая копия для просмотра/документации.
- `graph_explorer.html`: автономный браузерный просмотр; выбирайте супертему, кликайте ноды, масштабируйте колесом, двигайте граф мышью. Файлы JSON извне не загружаются.
- `diagnostic_flow.svg`: схема состояния и алгоритма диагностики.

Цвета: зелёный = атомарные темы (входящая степень 0); оранжевый = верховные темы (исходящая степень 0); синий = промежуточные темы; фиолетовый шестигранник = диагностический блок/супертема. Отдельные узлы могут быть одновременно атомарными и верховными (изолированные); у них двойная обводка.

**Типы рёбер принципиально различны.** Сплошная стрелка `A → B` = предпосылка знания. Штриховая стрелка `B ⇢ DG` = B оценивается диагностическим блоком DG, но не является предпосылкой для его изучения. В алгоритме топологической сортировки учитывать только сплошные стрелки.
