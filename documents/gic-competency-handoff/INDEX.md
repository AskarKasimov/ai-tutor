# Содержимое расширенного комплекта

1. `AGENT_START_PROMPT.md` — сообщение, которое пользователь может вставить в новый чат.
2. `AGENT_HANDOFF_COMPETENCY_GRAPH.md` — **главный подробный handoff**: цели, семантика, формат, файлы, качество, API и дорожная карта.
3. `GIC_diagnostic_handoff_v1/` — полные 53 файла актуальной версии продукта, включая canonical `data/course_graph.v1.json` и все визуализации.
4. `history/` — архивы всех предыдущих этапов для воспроизводимости решений. Не использовать эти версии вместо актуальной без специальной миграции.

**Не включён:** `AI_course_cleaned(1).zip` (~41 МБ) с оригинальными PDF и очищенным извлечением, включая РПД. Передайте отдельно, если агент будет проверять визуальные элементы, страницы или строить новый корпус.

## Контрольный запуск

```bash
cd GIC_diagnostic_handoff_v1
python -m unittest discover -s reference -p 'test_*.py' -v
python qa/check_artifact.py  # нужно установить networkx, jsonschema
```

Файлы с `full_text` могут содержать неточные формулы и пересекающиеся страницы; граф и DG-группы не прошли независимую преподавательскую валидацию. Все 145 рёбер `provisional`, во всех 20 DG `auto_close_allowed=false`.
