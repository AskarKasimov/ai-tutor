- **50 из 132** имеют русский перевод извлечённого английского текста (`full_text_ru`).

- Никакие сведения о графе, вопросы, `provides`, `requires`, рёбра, супертемы и ID **не изменены**.

## Основные файлы

- `course_graph.ru-draft.v1.1.json` — полный датасет 137 нод с оригинальным `full_text` и новым опциональным `full_text_ru`; текущий **основной результат**.
- `course_graph.ru-draft.schema.json` — JSON Schema для версии локализации 1.1.0.
- `gic_types.localized.ts` — TypeScript-интерфейсы, расширенные полями локализации.
- `translation_status.csv` — статус и объём перевода каждой ноды.
- `qa_translated_topics.csv` — журнал автоматической проверки целостности переведённых карточек.
- `pending_topics.csv` — оставшиеся для перевода темы с источником.
- `translation_jobs_pending.jsonl` — задания для автоматического перевода оставшихся 82 тем, одна строка = одна тема.
- `sample_translated_topics.md` — выборка пяти тем для двуязычной проверки.
- `manual_translations.py` — исходные тексты подготовленных переводов, пригодные для редактирования и сборки.
- `build_localization.py` — воспроизводимая пересборка и проверки из исходного GIC JSON; требует `jsonschema`.
- `import_translation_jobs.py` — импорт новых переводов из JSONL с проверкой, сохранением исходников и маркировкой как **непроверенных**.
- `TRANSLATION_QA_PROTOCOL.md` — инструкции для LLM-агента и редактора, политика терминологии и сверки формул.
- `translation_viewer.html` — автономный просмотрщик оригиналов/русского текста по нодам.

## Изменения формата

В каждой ноде к **неизменённым** полям добавлены:

```json
{
  "full_text": "[D..] Original English slide text...",
  "full_text_ru": "[D..] Русский перевод...",
  "translation_status": "translated_from_extracted_text",
  "translation_notes": []
}
```

Возможные статусы:

- `translated_from_extracted_text` — вручную переведено и отредактировано на основе извлечённого текста (не означает, что проверена вся графика PDF);
- `translated_draft_unreviewed` — будущий машинный перевод, **не допущен** к использованию без редакторской проверки;
- `pending_translation` — ожидает перевода;
- `no_source` — в курс не найден учебный текст.

Для UI: выбирайте `full_text_ru`, только если оно есть и статус допускает показ согласно вашей политике. Иначе показывайте `full_text` с пометкой «оригинал на английском», но никогда не подменяйте его вымышленным русским текстом.

## Как продолжить через LLM-агента

1. Передайте агенту `translation_jobs_pending.jsonl` и `TRANSLATION_QA_PROTOCOL.md`.
2. Обрабатывайте по одной ноде, **без пересказа** и без добавления знаний извне.
3. Каждая выходная запись JSONL: `{ "id": "AI-01-XX", "full_text_ru": "[D..] ..." }`.
4. После генерации вызывайте `python import_translation_jobs.py completed.jsonl`; новые материалы будут помечены как `translated_draft_unreviewed`.
5. Проводите проверку слайдов, графических формул, кода и терминов, после редакторского одобрения изменяйте статус конкретной ноды на `translated_from_extracted_text`.
6. Перед включением в продакшен проверяйте, что все ноды с источником имеют русский текст, не остаётся `pending_translation`/`translated_draft_unreviewed`, а все индексы эмбеддингов текстов обновлены.

**Запуск генерации переводов в текущей среде не поддерживался локальной установленной моделью перевода или доступным API.** Непереведённые тексты не были имитированы с помощью некачественного словарного заменителя.
