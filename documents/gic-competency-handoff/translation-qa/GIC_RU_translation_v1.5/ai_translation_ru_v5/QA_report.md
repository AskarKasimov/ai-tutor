## Что проверено автоматически

1. Полный JSON соответствует `course_graph.ru-draft.schema.json`.
2. Те же 137 ID в том же порядке, уникальные; все поля темы кроме `full_text_ru`, `translation_status`, `translation_notes` неизменны относительно v1.4.
3. Все графовые поля верхнего уровня (рёбра, блоки, требования, пробелы, семантика) совпадают побайтно на уровне структурного сравнения JSON с v1.4.
4. Для каждой из 132 нод последовательность маркеров источника `[Dxx | filename | с.N | label]` в английском и русском совпадает: страницы не выпали и не перепутаны.
5. Статусы: 132 `translated_from_extracted_text`, 5 `no_source`; ни одной оставшейся `pending_translation`.
6. Последняя партия в 22 переводов воспроизводит v1.5 из v1.4 через `translation_patch_batch5.jsonl`.
7. 132 узла и 145 рёбер образуют DAG; все 69 терминальных нод принадлежат ровно одной из 20 диагностических супертем.
8. Эвристический анализ русскоязычности 22 последних переводов обнаружил только три фрагмента с повышенной долей латиницы: два содержат обязательный код PDDL, третий содержит URL. Это не признаки забытых абзацев на английском.

## Ограничения контроля качества

Автоматические проверки обеспечивают структурную целостность и сохранение страниц, **не доказывают идеальность перевода**. Само извлечение текстового слоя исходных PDF местами повреждено. Большинство схем, диаграмм и встроенных рисунков ещё не прошло сквозной визуальный аудит; иногда русская запись дополняет повреждённую формулу обычным общепринятым обозначением и пометкой, что это реконструкция. Такие объяснения нельзя выдавать за дословное содержание PDF.
