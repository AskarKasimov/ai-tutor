# Gic — полная текстовая русская локализация, v1.5

**Статус:** 132/132 учебных нод имеют русский текст. Всего в графе 137 записей: ещё 5 — пробелы относительно РПД, без материалов, поэтому переводить в них нечего.

**Что включено:** английский оригинал и редакторский русский вариант на уровне всех извлечённых фрагментов привязанных страниц PDF. Сохранены идентификаторы тем, содержание вопросов и критериев, `provides`/`requires`, 145 prerequisite-рёбер и 20 диагностических супертем.

## Интеграция

1. Если проект ещё не импортировал локализацию, использовать целиком `course_graph.ru-draft.v1.5.json`.
2. Если уже используется версия 1.4, применить строки из `translation_patch_batch5.jsonl`, обновляя записи по стабильному `id`. **Не переписывать поля** `prerequisites`, `diagnostic_groups`, `question`, `provides`, `requires`, `full_text`.
3. В интерфейсе показывать `full_text_ru`, если статус `translated_from_extracted_text`; позволять открыть `full_text` для сверки. Темы `no_source` не включать в основной учебный маршрут.
4. Для воспроизводимой проверки выполнить `python validate_v5.py` (требуются `networkx` и `jsonschema`).

## Важная граница полноты

100% относятся **к количеству нод с переведённым извлечённым текстом**, а не к стопроцентному восстановлению каждого изображения, диаграммы или формулы в PDF. Искажённые OCR формулы, графические примеры и неоднозначные исходные объяснения описаны в замечаниях переводчика. Перед выдачей материала студентам нужен целевой визуальный аудит технических слайдов и экспертное ревью терминологии.
