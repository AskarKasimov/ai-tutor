# AI-01-17 — Кванторы и области действия

## Русский текст

[D06 | Tutorial 2.pdf | с.40 | core]
Кванторы.
Всеобщность: (∀x)P(x) означает, что P выполняется для всех значений x в области определения переменной. Пример: (∀x) dolphin(x) → mammal(x) — каждый дельфин является млекопитающим [для строгой записи следует поместить импликацию в область действия квантора].
Существование: (∃x)P(x) означает, что P выполняется хотя бы для одного значения x из области. Пример: (∃x)(mammal(x) ∧ lays_eggs(x)) — существует млекопитающее, откладывающее яйца. Это позволяет утверждать существование объекта, не называя его.

[D06 | Tutorial 2.pdf | с.41 | core]
Область действия кванторов.
Формулы логики первого порядка имеют структуру, подобную программам; переменные обладают областью действия. Например, «каждый живой человек кого-то любит»: (∀x)(alive(x) → (∃y)loves(x,y)). На слайде отдельно показаны области действия x и y. Скобки здесь проясняют предполагаемую интерпретацию.

[D06 | Tutorial 2.pdf | с.42 | core]
Порядок кванторов.
Перестановка одинаковых кванторов не меняет смысл: (∀x)(∀y)P(x,y) ≡ (∀y)(∀x)P(x,y), например «все собаки ненавидят всех кошек». Аналогично (∃x)(∃y)P(x,y) ≡ (∃y)(∃x)P(x,y), например «кошка убила собаку».
Перестановка разных кванторов меняет смысл: (∀x)(∃y)likes(x,y) — каждый кого-то любит; (∃y)(∀x)likes(x,y) — есть кто-то, кого любят все.

[D06 | Tutorial 2.pdf | с.43 | core]
Связь кванторов ∀ и ∃: обобщённые законы де Моргана.
1. (∀x)¬P(x) ≡ ¬(∃x)P(x): никто не обладает свойством P («ни одна собака не любит кошек»).
2. ¬(∀x)P(x) ≡ (∃x)¬P(x): не все обладают P («найдётся собака, которая не танцует»).
3. (∀x)P(x) ≡ ¬(∃x)¬P(x): все обладают P («нет собаки, которая не спит»).
4. (∃x)P(x) ≡ ¬(∀x)¬P(x): хотя бы один обладает P («существует говорящая собака»).
[В исходнике отсутствуют знаки эквивалентности между некоторыми частями формул.]

Упражнение II.
Используются предикаты Borders(x,y) («регион x граничит с регионом y») и Country(x) («x — страна»), а также константы географических регионов. Для каждой предложенной формулы определите: (1) правильно ли она передаёт предложение, или (2) синтаксически допустима, но смысл передаёт неверно.
«Все страны, граничащие с Эквадором, расположены в Южной Америке».
1. ∀c Country(c) ∧ Border(c,Ecuador) ∧ In(c,SouthAmerica)
2. ∀c Country(c) ∧ Border(c,Ecuador) ⇒ In(c,SouthAmerica)
3. ∀c Country(c) ⇒ [Border(c,Ecuador) ⇒ In(c,SouthAmerica)]
[Скобки во всех трёх записях на слайде неоднозначны; для корректной интерпретации их нужно расставить явно.]

[D06 | Tutorial 2.pdf | с.47 | core]
Упражнение II. Решение.
1. Конъюнкция «для любого c: это страна, она граничит с Эквадором и находится в Южной Америке» не эквивалентна исходной фразе.
2. Предполагаемая интерпретация: ∀c((Country(c) ∧ Border(c,Ecuador)) → In(c,SouthAmerica)); это правильная запись.
3. ∀c(Country(c) → (Border(c,Ecuador) → In(c,SouthAmerica))) логически эквивалентна 2 при корректной расстановке скобок.
На слайде приведена цепочка преобразований через ¬Country, ¬Border и дизъюнкцию с In(...); в этой цепочке есть повреждённая строка с отрицанием. Вывод об эквивалентности 2 и 3 верен при приведённых выше скобках.

Quantifiers
• Universal quantification
–(∀x)P(x) means P holds for all values of x in domain associated
with variable
–E.g., (∀x) dolphin(x) → mammal(x)
• Existential quantification
–(∃x)P(x) means P holds for some value of x in domain
associated with variable
–E.g., (∃x) mammal(x) ∧lays_eggs(x)
–This lets us make a statement about some object without
naming it

[D06 | Tutorial 2.pdf | с.41 | core]

–(∀x) alive(x) → (∃y) loves(x,y)

Quantifier Scope
• Switching order of universal quantifiers does not change the
meaning
– (∀x)(∀y)P(x,y)
(∀y)(∀x) P(x,y)
– “Dogs hate cats” (i.e., “all dogs hate all cats”)
• You can switch order of existential quantifiers
– (∃x)(∃y)P(x,y)
(∃y)(∃x) P(x,y)
– “A cat killed a dog”
• Switching order of universal and existential quantifiers does
change meaning:
– Everyone likes someone: (∀x)(∃y) likes(x,y)
– Someone is liked by everyone: (∃y)(∀x) likes(x,y)

[D06 | Tutorial 2.pdf | с.43 | core]
Connections between ∀and ∃
• We can relate sentences involving ∀and ∃using extensions to  De
Morgan’s laws:
1.(∀x) ¬P(x)
¬(∃x) P(x)
2.¬(∀x) P
(∃x) ¬P(x)
3.(∀x) P(x)
¬ (∃x) ¬P(x)
4.(∃x) P(x)
¬(∀x) ¬P(x)
• Examples
1. All dogs don’t like cats
No dogs like cats
2. Not all dogs dance
There is a dog that doesn’t dance
3. All dogs sleep
There is no dog that doesn’t sleep
4. There is a dog that talks
Not all dogs can’t talk
