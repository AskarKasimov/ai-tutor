Арифметические выражения.
Встроенный предикат `is` заставляет Prolog вычислить арифметическое выражение. При записи `X = 2 + 4` переменная X унифицируется с невычисленным термом `2+4`, а не с числом 6:
`?- X = 2 + 4.` → `X = 2+4`.
При записи `X is 2 + 4` правая часть предварительно вычисляется и затем связывается с X:
`?- X is 2 + 4.` → `X = 6`.

[D08 | Tutorial 4. Prolog.pdf | с.17 | shared]
Сравнение в Prolog (таблица операторов).
`X = Y` — успешная унификация двух термов; `X \= Y` — невозможность унификации.
`T1 == T2` — термы строго идентичны; `T1 \== T2` — неидентичны (даже если потенциально унифицируются).
`E1 =:= E2` — равенство численных значений арифметических выражений; `E1 =\= E2` — их неравенство.
`<`, `=<`, `>`, `>=` — числовые сравнения.
Порядок термов (стандартное упорядочение, а не обязательно алфавитное) может сравниваться `@<`, `@=<`, `@>`, `@>=`.
[Извлечённая таблица потеряла многие названия операторов и повторы строк. Здесь дана интерпретация стандартных операторов; точный состав слайда требует визуальной сверки.]

[D08 | Tutorial 4. Prolog.pdf | с.18 | shared]
Списки (LISTS) в Prolog.
Примеры: `[]`, `[1,2,3]`, `[4,chan]`, `[pen,apple]`, `[[pen,pineapple],[apple,pen]]`.
Голова и хвост (HEAD | TAIL): в `[1,2,3]` голова — `1`, хвост — `[2,3]`.
Шаблон `[H|T]` читается как «H, вертикальная черта, T» и сопоставляется с `[1,2,3]` как `[1|[2,3]]`.
Шаблон `[1,_,3]` использует анонимную переменную `_`; на её месте может быть `2`, `x`, список `[......]` или другой терм.

[D08 | Tutorial 4. Prolog.pdf | с.19 | shared]
Встроенные предикаты Prolog.
Проверка членства элемента в списке: `member(a, [a, b, c, d]).`
Проверка, что элементы удовлетворяют условию диапазона: `maplist(between(1, 3), [1, 2, 3]).`

[D20 | Week 4 Lecture.pdf | с.21 | core]
Типы данных.
В Prolog единый общий тип данных — *терм*; выделяют четыре разновидности термов:
1. Атомы.
2. Числа (целые и с плавающей точкой).
3. Переменные.
4. Составные термы.

[D20 | Week 4 Lecture.pdf | с.22 | core]
Атомы.
Атом — универсальное имя, не имеющее встроенного значения. Обычно начинается со строчной буквы либо заключается в одинарные кавычки.
Может включать буквы разного регистра, цифры и допустимые специальные символы (+ - * / < > = : ~ и др.).
Примеры: `cat`, `'Dog'`, `'another cat'`, `my_pet`, `myPet`.

[D20 | Week 4 Lecture.pdf | с.23 | core]
Переменные.
Имя переменной содержит буквы, цифры и подчёркивания; начинается с заглавной буквы или `_`.
Примеры: `X`, `_Y`, `Piano`, `Person_1`, `DOLL`.
Свободная переменная ещё не связана со значением; связанная уже получила привязку.
`?- 5 = 4.` → false: оператор `=` пытается унифицировать обе части.
`?- X = 5, X = 4.` → false: нельзя унифицировать X одновременно с 5 и 4.
`?- X = 5 + 4.` → X связан с термом `5+4`, это не арифметическое вычисление.
`?- X is 5 + 4.` → `X = 9`.
`?- X = Y, X = 5, Z is Y + 4.` → `X = 5, Y = 5, Z = 9`.
`?- 1 is mod(7/2).` — исходный пример поясняет остаток от деления 7 на 2. [Но запись не является корректным стандартным примером синтаксиса; ожидается `1 is 7 mod 2`.]
Анонимная переменная `_` скрывает конкретное значение:
`?- father(X,_).` — все отцы X без имён детей.
`?- father(X,Y).` — пары X (отец) и Y (ребёнок).

[D20 | Week 4 Lecture.pdf | с.24 | core]
Числовые сравнения в Prolog:
`X < Y` — строго меньше.
`X =< Y` — меньше или равно.
`X =:= Y` — численно равно.
`X =\= Y` — численно не равно.
`X >= Y` — больше или равно.
`X > Y` — строго больше.

[D20 | Week 4 Lecture.pdf | с.25 | core]
Составные термы.
Составной терм состоит из атома — функтора — и аргументов, которые сами являются термами. Обычно пишется `функтор(аргумент1, аргумент2, ...)`.
Число аргументов называется арностью (arity). Атом можно рассматривать как терм с арностью 0.
Примеры: `friend(max,peter).` и `person_friends(zelda, [tom,jim]).`

[D20 | Week 4 Lecture.pdf | с.26 | core]
Списки.
Список — упорядоченная коллекция термов; его элементы перечисляются в квадратных скобках через запятую. Список — разновидность составного терма.
Примеры: `[1,2,3]`, `[1]`, `[]`, `[red,green,blue].`

[D20 | Week 4 Lecture.pdf | с.27 | core]
Строки.
Строка — последовательность символов в двойных кавычках.
В зависимости от флага Prolog `double_quotes` она может интерпретироваться как список числовых кодов символов, список односимвольных атомов или атом. [Реализации Prolog также могут поддерживать отдельный строковый тип.]
Пример: `"to be, or not to be"`.

[D20 | Week 4 Lecture.pdf | с.28 | core]
Полезные операторы.
Отрицание как неудача: `not(term)` или `\+ term`.
`female(X) :- not(male(X)).`
`legal(X) :- \+ illegal(X).`
Неунифицируемость: `\=`. Пример: `X \= Y`.
Отсечение (cut) `!` прекращает поиск альтернатив после достижения данной точки; на слайде поясняется как «берёт только первый результат»:
`?- parent(Y,X), !.` — возвращает первую найденную пару родитель–ребёнок.
`write('Hello world!').` — выводит `Hello world!`.

Arithmetic Expressions
The is built-in predicate is used in Prolog to force the evaluation of
arithmetic expressions. If you just write something like X = 2 + 4, the
result is to bind X to the unevaluated term 2 + 4, not to 6. Example:
?- X = 2 + 4.
X = 2+4
If instead you write X is 2 + 4, Prolog arranges for the second
argument, the arithmetic expression 2 + 4, to be evaluated (giving the
result 6) before binding the result to X.
?- X is 2 + 4.
X = 6

Data Types
- Prolog's single data type is the term. There are 4 term types:
- Atoms
- Numbers (integers and floats)
- Variables
- Compound terms

[D20 | Week 4 Lecture.pdf | с.22 | core]
Atoms
- An atom is a general-purpose name with no inherent meaning
- Should begin with a lowercase letter or should be surrounded by single
quotes
- May contain uppercase letters, lowercase letters, digits (0-9),
characters (+-*/<>=:~)
- Examples:
- cat, ‘Dog’, ‘another cat’, my_pet, myPet

[D20 | Week 4 Lecture.pdf | с.23 | core]
Variables
- 
Variables consists of letters, digits and underscores. Variables start with uppercase letter or
underscore
- 
Examples:
- X, _Y, Piano, Person_1, DOLL
- 
Free variable is the one, for which the value was not assigned, bound is the opposite
- ?- 5 = 4 // false, ‘=’ is used for unification trying to bound both sides
- ?- X = 5, X = 4 // false, can’t be done for the second time
- ?- X = 5 + 4 // it is not a mathematical expression!
- ?- X is 5 + 4 // X = 9
- ?- X = Y, X = 5, Z is Y + 4 // X = 5, Y = 5, Z = 9
- ?- 1 is mod(7/2) // 1 is the remainder when 7 is divided by 2
- 
Anonymous variable denoted by ‘_’ makes the output for that variable invisible
- ?- father(X,_). // should return all fathers X without showing names of children
- ?- father(X,Y). // should return all pairs of fathers X and children Y names

[D20 | Week 4 Lecture.pdf | с.24 | core]
Comparing Integers
- X  <  Y     // x < y
- X  =<  Y   // x ≤ y
- X  =:=  Y  // x = y
- X  =\=  Y // x ⁄ = y
- X  >=  Y   // x ≥ y
- X  >  Y     // x > y

[D20 | Week 4 Lecture.pdf | с.25 | core]
Compound Terms
- A compound term is composed of an atom called a "functor" and a
number of "arguments", which are again terms
- Compound terms are ordinarily written as a functor followed by a comma-
separated list of argument terms, which is contained in parentheses
- The number of arguments is called the term's arity. An atom can be
regarded as a compound term with arity zero
- Examples:
- friend(max,peter).
- person_friends(zelda, [tom,jim]).

[D20 | Week 4 Lecture.pdf | с.26 | core]
List
- A list is an ordered collection of terms. It is denoted by square brackets with
the terms separated by commas
- It is a compound term type
- Examples:
- [1,2,3]
- [1]
- []
- [red,green,blue].

[D20 | Week 4 Lecture.pdf | с.27 | core]
Strings
- String is a sequence of characters surrounded by double quotes
- It is equivalent to either a list of (numeric) character codes, a list of
characters (atoms of length 1), or an atom depending on the value of the
Prolog flag double quotes
- It is a compound term type
- Examples:
- "to be, or not to be"

Useful Operators
- Negation: not(term) or \+ term
- female(X) :- not(male(X)).
- legal(X) :- \+ illegal(X).
- Not equal: \=
- X\=Y
- Cut: !
- Takes only the first result
- ?- parent(Y,X), !. // Even if there is more than 1 child with parent, will return only
// the first found pair, e.g. X=tom, Y=max
- write('Hello world!’). // prints Hello world!
