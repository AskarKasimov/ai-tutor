Арифметические выражения.
Встроенный предикат `is` заставляет Prolog вычислить арифметическое выражение. При записи `X = 2 + 4` переменная X унифицируется с невычисленным термом `2+4`, а не с числом 6:
`?- X = 2 + 4.` → `X = 2+4`.
При записи `X is 2 + 4` правая часть предварительно вычисляется и затем связывается с X:
`?- X is 2 + 4.` → `X = 6`.

[D08 | Tutorial 4. Prolog.pdf | с.17 | shared]
Сравнение в Prolog (таблица операторов).
`X = Y` — успешная унификация двух термов; `X \= Y` — невозможность унификации.
`T1 == T2` — термы строго идентичны; `T1 \== T2` — неидентичны (даже если потенциально унифицируются).
`E1 =:= E2` — равенство численных значений арифметических выражений; `E1 =\= E2` — их неравенство.
`<`, `=<`, `>`, `>=` — числовые сравнения.
Порядок термов (стандартное упорядочение, а не обязательно алфавитное) может сравниваться `@<`, `@=<`, `@>`, `@>=`.

Списки (LISTS) в Prolog.
Примеры: `[]`, `[1,2,3]`, `[4,chan]`, `[pen,apple]`, `[[pen,pineapple],[apple,pen]]`.
Голова и хвост (HEAD | TAIL): в `[1,2,3]` голова — `1`, хвост — `[2,3]`.
Шаблон `[H|T]` читается как «H, вертикальная черта, T» и сопоставляется с `[1,2,3]` как `[1|[2,3]]`.
Шаблон `[1,_,3]` использует анонимную переменную `_`; на её месте может быть `2`, `x`, список `[......]` или другой терм.

Упражнение I — решение расширенной задачи.
Рекурсивно найдите максимум списка:
`max_list([X], X).`
`max_list([H|T], Max) :-`
`    max_list(T, RestMax),`
`    Max is max(H, RestMax).`
База рекурсии: у одноэлементного списка максимум равен единственному элементу. Рекурсивный шаг: найдите максимум хвоста и сравните с головой.

Arithmetic Expressions
The is built-in predicate is used in Prolog to force the evaluation of
arithmetic expressions. If you just write something like X = 2 + 4, the
result is to bind X to the unevaluated term 2 + 4, not to 6. Example:
?- X = 2 + 4.
X = 2+4
If instead you write X is 2 + 4, Prolog arranges for the second
argument, the arithmetic expression 2 + 4, to be evaluated (giving the
result 6) before binding the result to X.
?- X is 2 + 4.
X = 6
