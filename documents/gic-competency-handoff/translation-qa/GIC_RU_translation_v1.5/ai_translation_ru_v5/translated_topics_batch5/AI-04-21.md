Мир Вампуса (Wumpus World).
Ранняя компьютерная игра об агенте, исследующем пещеру из комнат, соединённых проходами. В одной из комнат скрывается Вампус — чудовище, которое съедает вошедшего агента. Некоторые комнаты содержат бездонные ямы, куда падает любой пришедший, кроме слишком крупного Вампуса. Иногда в пещере встречаются кучки золота.

Правила мира Вампуса (2): восприятие.
- В клетке с Вампусом и по её ортогонально соседним клеткам ощущается запах (stench), по диагонали — нет.
- В ортогонально соседних с ямой клетках ощущается сквозняк (breeze).
- В клетке с золотом виден блеск (glitter).
- При столкновении со стеной ощущается удар (bump).
- После гибели Вампуса слышен крик (scream) во всей пещере.
Вход агента — список из пяти сигналов, например `[Stench, Breeze, Glitter, None, None]`, если есть запах, сквозняк и блеск, но нет удара и крика. Своё положение агент непосредственно не воспринимает.

[D02 | Lab 4 (without solution).pdf | с.14 | core]
Правила мира Вампуса (3): действия и награды.
Действия: идти вперёд; повернуть налево/направо на 90°; `Grab` — взять объект в текущей клетке; `Shoot` — выстрелить стрелой вперёд по прямой до Вампуса либо стены. Стрела только одна, поэтому лишь первый выстрел действует; `Climb` — покинуть пещеру, возможно только в начальной клетке.
Агент погибает, попав в яму или к живому Вампусу; клетка с мёртвым Вампусом безопасна, но пахнет.
Цель: взять золото и вернуться как можно быстрее без гибели. Награда +1000 за выход с золотом, штраф −1 за каждое действие и −10 000 за смерть.

Простой рефлексный агент.
Правила перевода сигналов восприятия в наблюдения:
`∀b,g,u,c,t Percept([Stench,b,g,u,c],t) → Stench(t)`.
`∀s,g,u,c,t Percept([s,Breeze,g,u,c],t) → Breeze(t)`.
`∀s,b,u,c,t Percept([s,b,Glitter,u,c],t) → AtGold(t)`.
Выбор действия по наблюдениям: `∀t AtGold(t) → Action(Grab,t)`.
Трудности: у агента нет непосредственного сигнала «пора выходить» — местоположение и факт наличия золота не входят в текущий percept. При возвращении в ранее посещённую клетку одинаковое восприятие может вызвать те же действия и цикл, если нет внутренней модели.

[D07 | Tutorial 3.pdf | с.36 | core]
Доказательство `W13`.
1. Modus Ponens к `¬S11` и R1: `¬W11 ∧ ¬W12 ∧ ¬W21`.
2. Устранение ∧: получаем `¬W11`, `¬W12`, `¬W21`.
3. Modus Ponens к `¬S21` и R2, затем устранение ∧: `¬W22`, `¬W21`, `¬W31`.
4. Modus Ponens к `S12` и R4: `W13 ∨ W12 ∨ W22 ∨ W11`.
5. Единичная резолюция с `¬W11`: `W13 ∨ W12 ∨ W22`.
6. Резолюция с `¬W22`: `W13 ∨ W12`.
7. Резолюция с `¬W12`: `W13`. Следовательно, Вампус в (1,3).

[D07 | Tutorial 3.pdf | с.44 | core]
Предпочтения при выборе действий.
Построенная база знаний Wumpus World затрудняет выбор лучшего действия среди допустимых. Например, правило выбора между «вперёд» и `Grab` должно было бы одновременно учитывать блеск при движении в клетку; это нарушает модульность.
Решение: отделить факты о действиях от фактов о целях. Тогда поведение агента можно перенастраивать, задавая другие цели.

[D07 | Tutorial 3.pdf | с.45 | core]
Шкала предпочтительности действий.
Сначала независимо оценим желательность действий: Great (отличное), Good (хорошее), Medium (среднее), Risky (рискованное), Deadly (смертельно опасное).
Агент выбирает лучшее доступное действие:
`∀a,s Great(a,s) → Action(a,s)`;
`∀a,s Good(a,s) ∧ ¬∃b Great(b,s) → Action(a,s)`;
`∀a,s Medium(a,s) ∧ (¬∃b Great(b,s) ∨ Good(b,s)) → Action(a,s)`; …
[В исходной формуле для Medium дизъюнкция даёт неочевидную семантику; при интерпретации приоритетов правильнее требовать отсутствие всех более качественных доступных действий. Нужна проверка слайда.]

[D07 | Tutorial 3.pdf | с.46 | core]
Применение шкалы качества действий. Пока агент не нашёл золото:
- Great: поднять обнаруженное золото; выбраться из пещеры с золотом.
- Good: перейти в безопасную клетку, где ещё не был.
- Medium: перейти в безопасную, уже посещённую клетку.
- Risky: перейти в клетку, о которой неизвестно, безопасна она или смертельно опасна.
- Deadly: перейти в клетку с заведомо известной ямой либо Вампусом.

Proving W13
• Apply MP with ¬S11  and  R1:
¬ W11 ∧¬ W12 ∧¬ W21
• Apply And-Elimination to this, yielding 3 sentences:
¬ W11, ¬ W12, ¬ W21

¬ W22, ¬ W21, ¬ W31

[D07 | Tutorial 3.pdf | с.44 | core]
Preferences among actions
• A problem with Wumpus world knowledge base that we have built so far
is that it is difficult to decide which action is best among a number of
possibilities.
• For example, to decide between a forward and a grab, axioms
describing when it is OK to move to a square would have to mention
glitter.
• This is not modular!
• We can solve this problem by separating facts about actions from
facts about goals. This way our agent can be reprogrammed just by
asking it to achieve different goals.

[D07 | Tutorial 3.pdf | с.45 | core]
Preferences among actions
• The first step is to describe the desirability of actions independent of
each other.
• In doing this we will use a simple scale: actions can be Great, Good,
Medium, Risky, or Deadly.
• Obviously, the agent should always do the best action it can find:
(∀a,s) Great(a,s) → Action(a,s)
(∀a,s) Good(a,s) ∧¬(∃b) Great(b,s)  → Action(a,s)
(∀a,s) Medium(a,s) ∧(¬(∃b) Great(b,s) ∨Good(b,s)) → Action(a,s)
...

[D07 | Tutorial 3.pdf | с.46 | core]
Preferences among actions
• We use this action quality scale in the following way.
• Until it finds the gold, the basic strategy for our agent is:
– Great actions include picking up the gold when found and
climbing out of the cave with the gold.
– Good actions include moving to a square that’s OK and hasn't
been visited yet.
– Medium actions include moving to a square that is OK and
has already been visited.
– Risky actions include moving to a square that is not known to
be deadly or OK.
– Deadly actions are moving into a square that is known to have
a pit or a Wumpus.
