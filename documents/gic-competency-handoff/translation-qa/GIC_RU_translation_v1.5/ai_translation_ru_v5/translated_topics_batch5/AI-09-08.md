Формулы Ant System (AS) для феромонов.
Количество феромона, оставленное k-м муравьём на ребре i→j, при обычной формулировке:
`Δτ_ij^k = Q/L_k`, если муравей k использовал ребро i→j, иначе `Δτ_ij^k = 0`.
Без испарения: `τ_ij ← τ_ij + Σ(k=1..m) Δτ_ij^k`.
С испарением: `τ_ij ← (1−ρ)τ_ij + Σ(k=1..m) Δτ_ij^k`.
Обозначения:
`Q` — постоянная; `i` — начальная вершина пути, `j` — конечная; `k` — номер муравья; `L_k` — стоимость построенного k-м муравьём пути; `m` — число муравьёв; `Δτ_ij^k` — вклад k-го муравья в феромон ребра i→j; `τ_ij` — общий уровень феромона на переходе; `ρ` — коэффициент испарения.

Алгоритм ACO.
Установить параметры и инициализировать феромонные следы.
Повторять до критерия остановки:
- для каждого муравья строить решение по вероятностному правилу переходов;
- выполнять локальное (online) обновление феромона;
- после генерации решений всеми муравьями применять локальный поиск;
- оценивать решения и запоминать лучшее;
- выполнить глобальное (offline) обновление феромона.

Алгоритм Ant System для TSP — блок-схема.
Инициализация, размещение каждого муравья в случайно выбранном городе.
Для каждого муравья повторяется выбор следующего города, пока остаются непосещённые города.
Затем муравей возвращается к начальному городу; феромон обновляется с учётом стоимости его тура.
Если критерий остановки выполнен, вывести лучший найденный тур; иначе повторить цикл.

Характеристики алгоритма ACO.
Феромон обновляется после построения решения:
`τ_new = (1−p)·τ_old + Δpheromone`.
`p` — коэффициент испарения.
Если ребро A→B входит в путь муравья: `Δpheromone = Q/L_k`, концентрация повышается (`Q` — постоянная, `L_k` — длина маршрута).
Если ребро не использовано, `Δpheromone = 0`, поэтому феромон уменьшается из-за испарения.

Необходимые параметры ACO:
1. Начальная популяция муравьёв (цикл муравьёв).
2. Общее число туров/проходов.
3. Скорость испарения.
4. Количество феромона, наносимого на часть цикла или маршрута.
5. Постоянная Q.

Правило перехода.
`τ_ij` — текущее количество феромона на ребре от города i к j.
`η_ij` — эвристическая привлекательность: в классической TSP обычно `1/distance(i,j)`, поэтому чем короче расстояние, тем выше η.
`p_ij^k` — вероятность, что k-й муравей выберет ребро i→j.
Находясь в городе i, он выбирает j только из ещё не посещённых городов `U_k`, а знаменатель вероятности суммирует веса всех таких кандидатов.
Стандартная форма: `p_ij^k = (τ_ij^α η_ij^β)/(Σ(l∈U_k) τ_il^α η_il^β)` для `j∈U_k` (иначе 0).

Глобальное обновление феромона.
`Δτ_ij^k` — вклад k-го муравья на ребро (i,j), `N_A` — количество муравьёв, `ρ` — скорость испарения, `L_k` — длина маршрута k-го муравья.
На следующей итерации: `τ_ij(new) = (1−ρ)τ_ij(old) + Σ(k=1..N_A) Δτ_ij^k`.
