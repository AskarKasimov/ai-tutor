## Воспроизведение

Для структурных проверок достаточно Python 3.11+: `python analyze.py`. Это не семантический оценщик: числовые различия, Markdown и LaTeX требуют ручного разбора.

Для оригинальных unit-тестов:

```sh
git worktree add --detach ../ai-tutor-translation-eval 801395bf344538a5fc1e43f9723591cd0ea7754e
cd ../ai-tutor-translation-eval/services/backend
go test ./internal/features/materials/infrastructure/translator -count=1
```

Для offline-проб скопировать `qa_probe_test.go` в исходный каталог `translator`, затем `go test ./internal/features/materials/infrastructure/translator -run TestQAProbe -v -count=1`. Эти четыре теста фиксируют известные дефекты baseline, а не утверждают, что такое поведение правильно.

Для повторения реального запуска скопировать `run_translator.go` в `services/backend/cmd/translationqa/main.go` отдельного checkout и собрать `go build -o translationqa.exe ./cmd/translationqa`. Затем запустить `launch.py --env-file <локальный .env> --binary <путь к exe> --limit 5 --ids AI-01-02,AI-04-07,AI-04-23,AI-08-05,AI-10-01`. Harness использует настоящий пакет translator и его исходный промпт, а не переписанный Python-аналог. Файл результатов append-only: уже присутствующие ID пропускаются; для независимого повтора используйте отдельную копию QA-каталога без результатов. Параметры доступа и секреты не публикуются.

В этом запуске пользователь явно разрешил передачу пяти оригиналов настроенному внутреннему серверу модели. Новый массовый запуск после отрицательного пилота не выполнялся. Docker, PostgreSQL, импорт материалов, OCR и cleaning не запускались: оценивается только переводчик.

## Ограничения приложенного пакета

`build_localization.py` содержит старый абсолютный путь `/mnt/data/GIC_diagnostic_handoff_v1`; перед пересборкой в другой среде потребуется адаптация пути. Исходник оставлен неизменным. Схема готового JSON проверена отдельно, его исходные поля сопоставлены с canonical v1. Исходная документация говорит о 50 переводах, но это только **13,2% текстового объёма курса**. Ни предоставленный перевод, ни пять результатов модели не проходили здесь полную постраничную сверку PDF.
