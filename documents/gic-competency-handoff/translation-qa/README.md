# Полная русская локализация GIC и выгрузка в Graph

`GIC_RU_translation_v1.5_complete.zip` от пользователя содержит 132 переведённые активные темы (100% имеющегося извлечённого текста) и 5 тем без учебных исходников. Архив распакован без редактирования в [GIC_RU_translation_v1.5](GIC_RU_translation_v1.5/ai_translation_ru_v5/README.md); полный исходный граф и дополнительная локализационная разметка остаются в этой handoff-ветке.

Проверены автоматическим validator из архива: JSON Schema; 137 стабильных ID; неизменность исходных полей, рёбер и DG; маркеры источников; точное применение патча v1.4→v1.5; 132 переводов; DAG из 145 рёбер. Это структурная проверка, не экспертная сверка каждого PDF.

Ветка `feat/gic-russian-course-graph` содержит только готовую к формату Фёдора фикстуру `api/fixtures/intro-to-ai.ru.graph.json` и короткое описание. В неё сериализованы 132 учебные темы и 20 диагностических групп как обычные Graph-ноды. Пять отсутствующих материалов не вошли. Сохранены 145 учебных рёбер; группы как диагностические верхние вершины связаны с назначенными им верховыми темами (69 дополнительных `prerequisites`). В исходном enriched-графе группы остаются отдельным слоем и не являются учебными компетенциями.

Чтобы повторить генерацию в корне репозитория, установи `networkx`, `jsonschema`, `PyYAML`, затем:

```powershell
python translation-qa/export_v15_to_fedia.py --repo ..\ai-tutor-gic-russian-pr
```

Экспорт проверяет оба Node-контракта из актуального master, ссылки и топологический порядок. Скрипт и enriched-источник не включены в PR в master; для полного следа остаются в этой ветке.

Перевод основан на извлечённом слое PDF. Формулы/диаграммы и отдельные технические темы требуют экспертного визуального ревью — см. локализационный [QA report](GIC_RU_translation_v1.5/ai_translation_ru_v5/QA_report.md).

Предыдущая проверка модуля Ваче на 5 выбранных темах сохранена в [отчёте пилота](REPORT.md). Текущий ручной перевод v1.5 заменяет тогдашний частичный пакет v1.1 как рабочую локализацию.
