# Формат учебного текста

Вопросы, учебное содержание, теория, подсказки и обратная связь — Markdown с GFM-таблицами. Frontend использует один `MarkdownContent`; первый абзац или Markdown-заголовок вопроса оформляется заголовком экрана. В разборе ответов уровни заголовков вопроса сдвигаются относительно h3. В сообщениях наставника первый абзац остаётся абзацем, а заголовки Markdown начинаются с h3 под заголовками страницы и темы. Ответы студента и голосовые инструкции остаются обычным текстом.

## Отображение

Таблицы и пояснения после кода находятся после закрывающих кавычек блока. Формулы в LaTeX рендерятся KaTeX через `remark-math` и `rehype-katex`: `$\frac{a+b}{2}$` внутри строки или отдельный блок с `$$` на отдельных строках. Unicode-формулы продолжают отображаться обычным текстом. В inline-коде и программных блоках LaTeX остаётся буквальным текстом. Ошибочная формула отображается исходным текстом и не прерывает показ остального содержимого. Сырой HTML не исполняется.

Блоки кода подсвечиваются через Light-сборку React Syntax Highlighter. Подключены Python, JavaScript, TypeScript, SQL, Go, Bash, JSON, Java, C/C++, Rust, CSS и XML/HTML; поддерживаются короткие метки `py`, `js`, `ts`, `sh`, `rs` и другие стандартные алиасы. Цвета задаются токенами Radix в SCSS и адаптируются к теме. Inline-код, блоки без языка и неизвестные языки остаются обычным моноширинным текстом. Подсветка сохраняет переносы, отступы и escape-последовательности и не выполняет код.

## LLM

Ответ модели остаётся JSON установленной структуры. Markdown находится внутри текстовых полей (`question`, `theory`, `feedback`, `assistant_text`, `summary` и других учебных полей). Внешний JSON не оборачивается кодовым блоком. Экранирование транспорта обрабатывает JSON-декодер; повторно заменять `\n` в декодированном тексте нельзя — это повреждает код.

Промпты явно задают Markdown и разделители LaTeX. В JSON обратные косые черты формул экранируются как `\\` и декодируются один раз; требования к длине, педагогике и структуре ответа сохраняются. Frontend отделяет переносом открывающий блок кода, если его разделитель склеен с пояснением на одной строке. Содержимое уже открытых блоков кода и inline-код не переписываются; остальная неверная разметка отображается как получена.
