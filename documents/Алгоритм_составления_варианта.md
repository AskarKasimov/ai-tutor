# Алгоритм сборки варианта

Дата: 7 октября 2026, сверено с кодом 15 октября 2026. Основа — текущая карта ML CSV/XLSX. Реализация и операции variantgen отмечены как implemented в [OpenAPI](../api/openapi.yaml).

## Фильтр компетенций

Обработать всю карту без выбора темы. Для каждого ОР оставить только TRUE, допустимые таксономию/важность и хотя бы одно готовое задание. Несколько аналогов одного ОР считаются одним ОР. Компетенция включается, только если у неё не меньше трёх подходящих ОР: основной и два базовых. Если подходящих ОР нет, она пропускается с причиной `NO_READY_OUTCOMES`; если их меньше трёх — `INSUFFICIENT_DISTINCT_OUTCOMES`. Код `INSUFFICIENT_LOWER_BLOOM_OUTCOMES` встречается только в снимках `competency-map-v3`.

Недостаточные компетенции пропускаются; вариант сохраняет список пропусков с причинами. Если не прошла ни одна, вернуть ошибку без создания пустого варианта.

## Выбор ОР

Для основного (решение встречи 10.10.2026: таксономия важнее важности): максимум ранга Блума; при равном ранге — большая важность; полное равенство — порядок карты.

Для базовых: исключить основной; из оставшихся выбрать два по рангу Блума по возрастанию, важности по убыванию, затем порядку карты. Ранг базового может совпадать с рангом основного, но не превышает его. Составляющие могут отличаться.

Текущие ранги: знание=1, понимание=2, применение=3, анализ=4; важность=1…5. Смысловые prerequisite-связи не задаются преподавателем и не доказываются этим автоматическим выбором.

## Выбор конкретных заданий

Каждый выбранный ОР имеет пул готовых аналогов с одинаковыми унаследованными свойствами. Случайно и равномерно выбрать одно задание внутри **того же ОР**. Если оно единственное, взять его. У main/basic разные ОР и task ID; подмена аналогом другого ОР не допускается.

При полном равенстве метаданных используется порядок источника (положение ОР в карте), затем стабильный fallback имени/ID. Все остальные решения детерминированы. Seed и воспроизводимость генерации не требуются; выбранные задачи фиксируются в БД и не меняются при повторном чтении.

## Источник и результат

Колонки/формат карты остаются прежними. Преподаватель добавляет полные Задание N и больше TRUE. Полная ячейка содержит четыре блока без подписей, разделённых двумя пустыми строками: вопрос, варианты (нумерованный Markdown-список или `[]`), голосовую инструкцию и эталон — см. [формат учебного текста](markdown-content.md). Для включения в вариант нужны непустые вопрос, голосовая инструкция и эталон. Неполные фрагменты не считаются заданиями. Ручные роли, связи, группы и дополнительные документы не требуются.

LLM-генератор taskgen сохраняется отдельным действующим модулем; готовые задачи того же ОР могут участвовать в пуле наряду с авторскими.

Для каждой включённой компетенции результат содержит main + два basic и снимки вопросов/профилей. Сохраняются исходные ID, данные для грейдинга и пропущенные компетенции. История читается после переимпорта.

Доступ variantgen: создание и список вариантов, чтение варианта и отдельной позиции. Публичный API сразу возвращает main и доступные basic, скрывая эталоны, criteria, ОС и сырой снимок; серверный reader для грейдинга возвращает полный снимок с проверкой владельца, включая связанные свойства ОР/ОС, ALDs, темы и РПД. Ответы, оценки и переходы реализованы отдельным `diagnostic`, итоговый фидбэк — `diagnosticfeedback`, план обучения — `learning`.

Новые варианты используют `competency-map-v4` (основной по рангу Блума, затем по важности, всегда с двумя базовыми). Снимки `competency-map-v1`–`v3` сохраняют прежний состав и доступны без пересборки; в v3 основной выбирался по сумме ранга Блума и важности, а базовые были строго ниже его по Блуму. `task_count` в варианте и истории, `total_tasks` в сессии и результате равны числу сохранённых позиций, а не числу компетенций × 3. Сумма диагностики включает основные и предъявленные базовые задания; максимум — 3 × число включённых компетенций. При main=3 пропускаются только имеющиеся basic; при main=0/1 проходятся все имеющиеся basic, затем следующая компетенция. Отсутствующие basic не учитываются в `untested_basics`.
