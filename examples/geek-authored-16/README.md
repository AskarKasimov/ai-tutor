# Демо: 16 авторских вопросов

Ветка `demo/geek-authored-16` сохраняет авторский вариант Geek отдельно от работы
с новой картой Марины и числовыми рубриками.

`graph.json` — сохранённый готовый граф: все 16 вопросов, теория, критерии,
зависимости, варианты и подготовленные переформулировки. Это данные графа,
а не экспорт базы и не исходный XLSX. Секретов и пользовательских ответов здесь нет.

На локальном стенде этому графу соответствует отдельный курс:
`https://localhost:8443/exam?subject_id=subject_8eFXXeAlDc-6uk7qMgpygxU_3AzF_YapkBeUtiBbj1U`.
Ссылка работает, пока сохранена база этого стенда. JSON хранится в Git независимо
от Docker и базы; он не импортируется через экран загрузки XLSX автоматически.

В коде восстановлено оценивание К1–К4 до перехода на числовые пункты КК Марины.
Сохранены персональный фидбек, уточнения и переформулировки, отдельная обработка
служебных реплик, показ текста до озвучки и озвучка блоками.
Промежуточного Git-коммита перед переходом на рубрики не было: этот вариант
восстановлен из рабочего снимка `f8f84150` удалением новой интеграции рубрик.
Это реконструкция прежней логики, а не побайтовый исторический снимок.

Рабочий стенд и его база при создании этой ветки не переключались.
Для демонстрации код нужно запускать именно из этой ветки; один только выбор
старого курса на стенде с новым кодом не переключает реализацию оценщика.
