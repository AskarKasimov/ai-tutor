# Общая библиотека аудио

Чистый Go-модуль для backend и voice gateway: структурный разбор RIFF/WAV, метаданные формата, разбиение PCM16 по тихим местам и склейка частей. Сети, конфигурации моделей и учебной логики здесь нет.

`InspectWAV` возвращает метаданные только для структурно корректного файла. Допустимые частоты — правило вызывающего слоя: backend и voice gateway принимают для STT 8–192 кГц. `SplitWAV` и `TooManyParts` получают явный предел числа частей; в voice gateway он равен 100. Backend использует единственную реализацию `JoinWAV` при озвучке длинного текста.

Проверки из этого каталога, последовательно: `GOMAXPROCS=2 go test -p 1 -parallel 2 -race ./...`, затем `GOMAXPROCS=2 go vet -p 1 ./...`. После изменения библиотеки проверяйте backend и voice gateway их командами.
