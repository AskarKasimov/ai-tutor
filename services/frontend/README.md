# Frontend AI Tutor

React 19, TypeScript, Vite 8,
TanStack Router (файловые маршруты), TanStack Query, i18next / react-i18next,
SCSS Modules, Vitest и Testing Library. Для UI используется Radix Themes.

## Запуск

Требуется Node.js 22.12+ и npm. Из этой директории:

```bash
npm ci
npm run dev
```

Откройте http://localhost:5173. На `/` находится прототип голосового
тренажёра с одним фиксированным вопросом о прогнозе возврата кредита и четырьмя вариантами ответа.

Запись настоящая: разрешите микрофон, ответьте, завершите запись и прослушайте
сохранённое аудио. После остановки запись отправляется в голосовой API, интерфейс
показывает настоящую расшифровку, затем балл 0/1/2 и три строки фидбэка от модели через backend. Кнопка
«Посмотреть пример» отдельно открывает явно подписанный демонстрационный результат.
Повтор возвращает тот же вопрос. Кнопка «Прослушать инструкцию» озвучивает отдельную голосовую инструкцию через API синтеза, без
подмены браузерным SpeechSynthesis. Для микрофона нужен HTTPS или localhost.

Фронтенд обращается к ручкам нашего backend:

- `POST /api/v1/voice/transcriptions`: multipart с полем `audio`, ответ `{ "text": "..." }`.
- `POST /api/v1/voice/syntheses`: JSON `{ "text": "..." }`, WAV в ответе.
- `POST /api/v1/assessments/evaluate`: `transcription_id`, текст задания, варианты, голосовая инструкция и необязательный эталон; ответ `{ "score": 0..2, "feedback": ["...", "...", "..."] }`.

Оценка не сохраняется. При сбое модели расшифровка остаётся на экране, и её можно
отправить на повторную оценку без новой записи. Текущее задание передаётся с frontend
как прототипные данные; опубликованный банк заданий и серверная рубрика ещё не подключены.

Для гостя автоматически открывается обязательная модалка `react-modal`
с входом и регистрацией. Закрыть её можно только успешной авторизацией;
Escape и клик по фону не закрывают форму. После выхода модалка появляется снова.
Формы вызывают `/api/v1/auth/login` и `/api/v1/auth/register`, регистрация
сразу создаёт сессию. После перезагрузки пользователь загружается через
`/api/v1/auth/me`; кнопка «Выйти» завершает сессию. Пароль при регистрации —
15–128 символов, имя необязательно.

Cookies сессии передаются вместе с запросами. Backend требует авторизацию;
при HTTP 401 интерфейс показывает сообщение о необходимости войти.
Таймаут запросов — 120 секунд. Сервисы моделей вызывает backend, их адреса
во фронтенде не нужны.

Настройки находятся в общем корневом `.env` монорепозитория
(игнорируется Git), образец — корневой `.env.example`:

```dotenv
VITE_API_BASE_URL=/api/v1
VITE_API_PROXY_TARGET=http://127.0.0.1:8002
```

Vite читает env из корня монорепозитория, в том числе при запуске из
`services/frontend`. В dev-режиме Vite проксирует `/api/v1` на локальный backend и удаляет префикс.
После изменения env перезапустите `npm run dev`.
Для проверки сессии с Secure cookies используйте HTTPS через Compose.
В Compose запросы идут на тот же origin через Caddy. Значение `/api/v1`
используется по умолчанию. Compose передаёт `VITE_API_BASE_URL` из корневого
`.env` как аргумент сборки. После его изменения пересоберите frontend.
Прямой `docker build` поддерживает `--build-arg VITE_API_BASE_URL=...`.
Реальная сеть голосовых моделей не проверялась; HTTP-контракт проверяется тестами.

Макет: https://www.figma.com/design/0QMZU6tpUJCFmtZKMkYn4B/?node-id=41-2.
Локальные SVG в `public/assets/voice-trainer/` получены из фрейма `67:2`:
фон (`layer-0`), знак (`layer-1`), разделитель (`layer-2`), карточка (`layer-3`),
область ответа (`layer-4`), повтор (`layer-5`), шапка (`layer-6`), запись (`layer-7`).
Inter Regular/Bold загружены из Google Fonts; приложение не запрашивает шрифты
или временные ассеты Figma во время работы.

## Структура

- `src/app/` — запуск, провайдеры Radix/Query и глобальные стили.
- `src/routes/` — файловые маршруты и их SCSS Modules.
- `src/i18n/` — локализация; пользовательский текст хранится в переводах.
- `src/shared/` — место для общих компонентов, типов и утилит.
- `src/data/` — место для контрактов данных и query/mutation hooks.
- `src/mocks/` — место для тестовых источников данных и фикстур.
- `src/platform/` — место для адаптеров браузерных API.
- `src/test/` — настройка Testing Library и jsdom.

`src/routeTree.gen.ts` генерируется плагином Router при запуске Vite/Vitest
или сборке. После добавления маршрутов сначала запустите `npm run dev`
либо `npm run build`, затем typecheck. Сгенерированный файл хранится в Git.
Правила разработки находятся в [AGENTS.md](AGENTS.md).

## Проверки

```bash
npm run lint
npm run typecheck
npm test -- --run
npm run build
```

Эти же проверки выполняются в Frontend CI. `npm run preview` запускает
предпросмотр готовой сборки.

## Docker

Из корня монорепозитория:

```bash
docker build -t ai-tutor-frontend services/frontend
docker run --rm -p 8080:80 ai-tutor-frontend
```

Сборка обслуживается nginx на http://localhost:8080 с fallback для SPA-маршрутов.
Фронтенд включён в общий Docker Compose. Для запуска всего приложения
выполните `./run.sh -d` из корня монорепозитория после настройки `.env`
по корневому README. Приложение доступно на https://localhost:8443; Caddy
направляет `/api/v1` и `/api/v1/*` в backend, удаляя префикс `/api/v1`.
Проверка backend доступна на `/api/v1/health`; остальные пути идут во frontend.
Порт nginx доступен только внутри Docker-сети.
