# Сервис распознавания материалов (OCR / Docling)

Сервис `services/ocr/` выполняет извлечение структурированного текста из презентаций и документов (PDF, Markdown, текстовые файлы) с сохранением формул LaTeX и разбивкой по слайдам/страницам.

## Архитектура и запуск

- Сервис реализован на Python (FastAPI + Docling / pypdf) и запускается в Docker-контейнере `ocr`.
- В сети `ai-tutor_default` сервис доступен бэкенду по адресу `http://ocr:8000` (`BACKEND_OCR_URL`).
- Эндпоинты:
  - `GET /health` — проверка работоспособности сервиса.
  - `POST /convert` — multipart загрузка файла для распознавания; возвращает `{"markdown": "..."}`.

В общем Compose-стеке сервис описан в `services/ocr/docker-compose.yaml` и подключается в корневом `docker-compose.yaml`.
